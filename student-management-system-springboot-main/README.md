# Student Management System (Angular + Spring Boot + MySQL)

Start with `README-RUN-WINDOWS.txt`. The easiest option is to run `RUN-ALL.bat` after installing Java 21, Node.js, and MySQL.

- `student-management-frontend/` — Angular frontend and routes.
- `studentmanagement/` — original Spring Boot backend plus REST API endpoints for the Angular app.
- `student_management_template/` — original 15 HTML pages and CSS, preserved.
